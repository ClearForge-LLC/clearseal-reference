# clearseal-reference

Reference implementation of the [ClearSeal](https://github.com/ClearForge-LLC/ClearSeal-public)
standard for LLM-access nodes — one core that implements every control, and three editions that
carry it: a **teaching** edition to read, and quickly deployable **Linux host** and **Windows host**
editions to run.

**Status (2026-09-24): genesis in progress. Nothing is built.** The four steering documents
(`docs/northstar.md`, `docs/architecture.md`, `docs/roadmap.md`, and this README) land in the first
pull request. Until they do, this file is the only thing here, and it says so.
